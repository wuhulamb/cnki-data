# 中国城市统计年鉴数据

`data.json` 通过 `all_data.py` 从中国知网（CNKI）城市统计数据库 API 爬取而来。

## data.json 数据结构

```json
{
  "指标名称": {
    "城市名称": {
      "年份": "数值",
      ...
    },
    ...
  },
  ...
}
```

### 示例

```json
{
  "GDP(亿元)": {
    "上海市": {
      "2000年": "4771.0",
      "2001年": "5210.0",
      ...
    },
    "北京市": { ... },
    ...
  },
  "常住人口数(万人)": { ... },
  ...
}
```

## 数据规模

| 项目 | 数量 |
|------|------|
| 指标总数 | **838** |
| 数据点总数 | **2,235,289** |
| 空值率 | **0%** |

## 覆盖范围

- **指标（838个）**：包括 GDP、人口、财政、教育、医疗、环境等经济社会统计指标
- **城市**：覆盖中国地级市（333个左右），部分指标覆盖范围较广，部分仅覆盖少量城市
- **时间跨度**：2000年 ~ 2023年（年度数据）

## 指标来源

指标定义及分类结构存储在 `indicator.json`，包含层次化的指标树（顶层约7大类，叶子节点共838个）。

## 注意

1. **年份覆盖不统一** — 不同指标的年份范围差异很大：
   - 最少：仅 1 年（如城镇常住人口仅 2020 年）
   - 最多：24 年（2000-2023）
   - 约 20% 的指标覆盖 17 年以上

2. **数值均为字符串** — 如 `"1916.0"`、`"38700.0"`，使用时需 `float()` 转换

3. **仅年度频率** — 数据为年度统计值，无月度/季度粒度

4. **2023 年数据点较少** — 相比往年显著减少，可能因统计滞后

5. **数据可能缺失** — 某些城市在某些年份可能没有数据（key 不存在而非值为空）

6. **地区范围差异** — 不同指标覆盖的城市数量不同：
   - 部分指标覆盖 300+ 城市（全国地级市）
   - 部分仅覆盖个别城市或省份
