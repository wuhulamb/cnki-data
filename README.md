# 中国城市统计年鉴数据

`data.json` 通过 `all_data.py` 从中国知网（CNKI）城市统计数据库 API 爬取而来。

## data.json 数据结构

```json
{
  "指标名称": {
    "城市名称": {
      "年份": "数值",
      ...
    },
    ...
  },
  ...
}
```

### 示例

```json
{
  "GDP(亿元)": {
    "上海市": {
      "2000年": "4771.0",
      "2001年": "5210.0",
      ...
    },
    "北京市": { ... },
    ...
  },
  "常住人口数(万人)": { ... },
  ...
}
```

## 数据规模

| 项目 | 数量 |
|------|------|
| 指标总数 | **838** |
| 数据点总数 | **2,235,289** |
| 空值率 | **0%** |

## 覆盖范围

- **指标（838个）**：包括 GDP、人口、财政、教育、医疗、环境等经济社会统计指标
- **城市**：覆盖中国地级市（333个左右），部分指标覆盖范围较广，部分仅覆盖少量城市
- **时间跨度**：2000年 ~ 2023年（年度数据）

## 指标来源

指标定义及分类结构存储在 `indicator.json`，包含层次化的指标树（顶层约7大类，叶子节点共838个）。

## 中国_市.geojson 数据结构

中国城市行政区划矢量边界数据。

### 概览

| 项目 | 内容 |
|------|------|
| 坐标参考系（CRS） | **EPSG:4490**（CGCS2000 国家大地坐标系） |
| 类型 | `FeatureCollection` |
| 要素总数 | **388** |

### 要素结构

```json
{
  "type": "Feature",
  "properties": {
    "name": "梅州市",
    "gb": "156441400"
  },
  "geometry": {
    "type": "MultiPolygon",
    "coordinates": [...]
  }
}
```

### 要素分类

| 类型 | 数量 | 几何类型 | 说明 |
|------|------|----------|------|
| 城市面要素 | **375** | `MultiPolygon` | 各地级市/直辖市行政区划面 |
| 境界线 | **13** | `MultiLineString` | 国界/省界等边界线（name=境界线） |

### GB 代码说明

`gb` 字段为 9 位数字，格式为 **156 + 6 位 GB/T 2260 地区代码**：
- `gb=156441400` → 去掉前缀 `156` 得 adcode=**441400**（梅州市）
- 与 `china.csv` 中的 adcode 可关联（去掉 `156` 前缀后 **372/375** 可匹配）
- 3 个不匹配的地区（非标准行政区划，为特殊管理区域）：
  | adcode | 名称 | 说明 |
  |--------|------|------|
  | 629700 | 中农发山丹马场 | 位于甘肃，原央企管理的农场/马场 |
  | 629800 | 莲花山风景林自然保护区 | 位于甘肃，自然保护区 |
  | 629900 | 太子山天然林保护区 | 位于甘肃，天然林保护区 |
- `data.json` 中的城市名称可通过 adcode 关联到 GeoJSON 的空间边界

### 坐标精度

6 位小数，示例：`[115.884064, 24.928957]`

## 注意

1. **年份覆盖不统一** — 不同指标的年份范围差异很大：
   - 最少：仅 1 年（如城镇常住人口仅 2020 年）
   - 最多：24 年（2000-2023）
   - 约 20% 的指标覆盖 17 年以上

2. **数值均为字符串** — 如 `"1916.0"`、`"38700.0"`，使用时需 `float()` 转换

3. **仅年度频率** — 数据为年度统计值，无月度/季度粒度

4. **2023 年数据点较少** — 相比往年显著减少，可能因统计滞后

5. **数据可能缺失** — 某些城市在某些年份可能没有数据（key 不存在而非值为空）

6. **地区范围差异** — 不同指标覆盖的城市数量不同：
   - 部分指标覆盖 300+ 城市（全国地级市）
   - 部分仅覆盖个别城市或省份
